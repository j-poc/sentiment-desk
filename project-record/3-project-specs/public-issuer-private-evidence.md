## Current scope

User-owned private research material is in scope only as evidence about an issuer already present in Sentiment Desk's configured publicly listed company inventory. Privately held companies are out of scope: this feature cannot create, discover, monitor, count, rank, or add a profile for one. A private-company name may appear incidentally inside an attributed source passage, but it does not become a covered company.

Private material is optional and is never required to reach first-run value. The initial supported inputs are a manually written research note or user-selected UTF-8 `.txt`, `.md`, or `.csv` file. The config parser requires each eligible issuer to carry the curated `listingStatus: "publicly_listed"` marker; the private-evidence API also enforces the runtime allowlist derived from that parsed config. The app stores the exact text, a content digest, a user-entered title and source label, an optional user-asserted source date, the import time, and an optional filename. It does not infer a publication or event time from the import time or file metadata. Each item is limited to 128 KiB and 40,000 Unicode code points; the local store is limited to 250 items and 8 MiB of content.

The app keeps private evidence separate from public source observations, public sentiment charts, counts, baselines, alerts, Jev judgments, and automatic Luna classifications. Adding, reading, or deleting it makes no collector or market-data request. The user explicitly authorized support for sending one selected item to OpenAI GPT-6 Luna, but never for automatic forwarding. That action names the exact item and company, OpenAI as the recipient, the API data controls, and requires an in-app confirmation. The Responses API uses `store: false`, no tools, and explicit prompt-cache mode without breakpoints. OpenAI default API abuse monitoring may retain prompts and responses for up to 30 days; the account's retention configuration is unverified. The selected result, exact-evidence quotes, uncertainty, response hashes, and usage are saved only in the separate private store and never included in public sentiment or classifier counts. A digest-bound one-attempt record is written before dispatch so duplicate clicks or uncertain network outcomes do not trigger automatic repeat charges. Account approval, provider key, operator feature flag, external-request gate, writable private/public stores, shared daily request/byte/USD caps, and strict OpenAI response validation are mandatory; missing any gate leaves the item local and visibly unanalyzed.

## Local storage and boundaries

Private evidence lives in a separate SQLite store under a directory restricted to the local operating-system account, with owner-only file permissions. It is not application-encrypted. The UI and operator documentation say that the content remains on this device unless the user explicitly confirms a selected GPT-6 Luna action, and is separate from public sentiment; deletion removes it from the active store, while operating-system snapshots or user-managed backups may retain older copies. No private evidence is written to logs, browser storage, git, or public-source tables.

The feature is unavailable unless the server is bound to a loopback address. Write and content-read requests require local same-origin checks, JSON content type for writes, and the exact configured public-issuer identifier plus the curated listing allowlist. A request for a company outside the configured public-company inventory fails closed. The storage path, number of records, note size, total stored bytes, SQLite file size, request body, and minimum free disk headroom are bounded; imports reject unsupported file types, invalid UTF-8, empty content, oversize content, and unsafe metadata without partial writes. Users can open an exact saved item and delete it. Reads return only the selected company's material. The standard Docker Compose service binds inside the container to `0.0.0.0`; its loopback-only published host port does not make the private store available, so use the native loopback-bound app for this workflow until a container network boundary is independently verified.

## Explicitly not claimed

This slice does not parse PDFs or spreadsheets, create a private-company profile, synthesize an investment conclusion, or establish that a stored note is true or relevant. GPT-6 Luna output is an unverified analyst aid, not a source fact, Jev score, investment conclusion, or recommendation.
